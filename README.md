# Simulación de Sistema de Parqueaderos

## Integrantes

- Andrés Felipe Meléndez Acevedo
- Nerlis Vanessa Pérez Salas

## Descripción

Este proyecto desarrolla una simulación de un sistema de pago de parqueaderos mediante un modelo de colas M/M/1 con tres cajeros independientes.

## Herramientas utilizadas

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- SciPy

## Resultados principales

- Mejor cajero: Cajero 3
- Peor cajero: Cajero 2
- Tiempo promedio de espera: 1.67 minutos
- Estado estable: 500 observaciones
- Réplicas ejecutadas: 30

## Conclusión

Los tres cajeros son suficientes para atender la demanda actual del sistema.
